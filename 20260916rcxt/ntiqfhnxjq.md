# 河南新版预防接种证启用，有啥变化？

> 更新时间：2026-09-16 (UTC+8)

每个孩子出生后，都将会拥有一个小本本——预防接种证。

近期，河南省2023版预防接种证已陆续启用，新版和旧版有何不同？拥有旧版的需要更换为新版吗？河南省疾控中心免疫规划所相关专家进行了权威解答。
**新版与旧版有什么不同?**
新版预防接种证采用全新设计、标识和制作工艺，内容进一步精简，完善了各项内容的英文翻译，便于接种单位打印接种信息，更有利于受种者监护人方便快捷查询预防接种信息。

新版在原来的基础上保留了接种预约页，增加了更多的接种记录页，方便家长查询儿童的接种情况。为方便儿童入托、入学接种查验，新版接种证还增加了入托、入学预防接种完成情况评估页。
**持有旧版的是否需要更新新版接种证?**
答案是，不需要。

新版接种证只是在内容上有部分更新，与旧版接种证在功能上没有差别。无论是新版接种证还是旧版接种证，在预防接种、入学入托、出境查验等场景下，都具有同样的作用。
**宝宝出生后，如何办理预防接种证?**
在宝宝出生后一个月内，其监护人应当携带产科接种单位开具的《新生儿预防接种信息登记表》，**到宝宝户口所在地或居住地预防接种单位办理预防接种证**。焦作等部分地区可在出生时的产科接种单位办理。

办理接种证前，可提前电话咨询预防接种单位办理接种证的时间、所需资料(一般需要出生证明、户口本)等信息。**预防接种单位咨询电话，可通过当地卫生健康行政部门、疾控机构发布的信息进行查询。**
**预防接种有哪些作用?**
主要有这六大作用：

1. 儿童在每次接种疫苗时，应携带并出示。

2. 记录各种疫苗接种信息，包括接种日期、生产企业、接种剂次、疫苗批号、接种单位与接种人等信息。

3. 儿童入托、入学时，查验疫苗接种记录的凭证。

4. 出国后有关疫苗接种的证明。

5. 宣传预防接种知识，儿童家长获知免疫程序的重要途径。

6. 预约疫苗接种。
**如果接种证丢失或损坏怎么办?**
儿童家长应妥善保管接种证，如果接种证丢失或损坏，可以前往接种所在的接种单位，申请挂失或补办预防接种证。需要提供身份证或户口簿等身份证明材料。
**可以手动更改接种信息吗?**
接种证上的接种记录，应由接种单位根据宝宝实际接种情况进行记录。建议宝宝家长不要手动更改预防接种证上的疫苗信息，以确保记录的准确性。

**如发现接种证上存在错误，可以前往接种单位进行更改**，需要提供正确的接种信息和身份证明材料。
**可在不同接种单位接种疫苗吗?**
目前，河南省已建立了省级预防接种信息管理系统，能够实现不同接种单位接种记录的信息共享和汇总。

**宝宝接种疫苗优先考虑在居住地接种单位接种，也可以在省内其他接种单位接种疫苗后打印接种信息。**
**未带接种证可打疫苗吗?**
接种证是接种单位记录宝宝接种信息的有效凭证。未携带接种证，可能造成宝宝的接种信息无法及时打印。忘记携带接种证时，接种单位可能会要求儿童家长取回接种证后再给予接种。建议宝宝家长接种前一定要携带预防接种证，以免来回折腾。
**接种信息可以网络查询吗?**
接种疫苗后24小时，宝宝家长可以通过“**河南疾控**”、“**河南健康****豫事办**”手机App进行查询。
**接种疫苗温馨提示**
(一)接种前注意事项

1.国家免疫规划疫苗对适龄儿童实行免费接种，非免疫规划疫苗“知情、自愿、自费”接种。

2.宝宝应按照国家免疫规划疫苗儿童免疫程序、疫苗使用指导原则和接种方案等接受预防接种；**如果发现宝宝漏种疫苗，应及时补种。**

3.家长(监护人)应当了解预防接种相关知识，并于接种前如实反映孩子近期健康状况、既往接种史和反应史，孩子及家庭成员的过敏史和患病史等。接种前做好生活护理准备，**保持接种部位清洁，换上干净、宽松的衣服**，便于露出接种部位。

4.如您对使用的疫苗、注射器或接种操作有疑问，可暂缓接种，并可咨询接种医生或疾病预防控制机构。

(二)接种后注意事项

**1.接种后应留在接种单位观察30分钟**，无异常后方可离开。接种后如有发热、接种部位红肿、硬结等反应，除对症治疗外还应及时告知接种单位医生做好相关记录。

2.极个别人可能会出现过敏、高热不退或伴有其他全身症状、异常哭闹等情况，应及时到医院诊治。

3.接种后保持接种部位的清洁。防止继发感染，接种后不揉搓接种部位，2天内不洗澡。

**4.接种后48小时内尽量多喝水，不要让宝宝做剧烈活动。**

5.不在宝宝房间内吸烟，不让宝宝仰睡喝奶，宝宝睡觉时穿的衣服太厚、太紧或盖的被子太厚重有可能引起婴儿窒息。

6.到目前为止，任何疫苗的保护效果都不能达到100%，少数人接种后未产生保护力，与疫苗本身特性和受种者个人体质有关。
